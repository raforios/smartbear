Playground ML

Experimenta con los algoritmos de ML_FUNCTIONS: regresión lineal y logística (cost / gradient / train / predict), sigmoid en batch y normalización Z-score. Cada panel se conecta directo al microservicio. Las matrices se ingresan como JSON.

Entrenar (Linear Regression)

Ejecuta gradiente descendente con tus datos. Devuelve los pesos finales y el historial de costo para visualizar la convergencia.

Predecir (Linear Regression)

Usa los pesos entrenados (o tus propios valores) para calcular predicciones sobre nuevos puntos.

Cost / Gradient (Linear)

Inspecciona el costo y el gradiente para un set de pesos cualquiera (sin entrenar).

Entrenar (Logistic Regression)

Gradiente descendente para clasificación binaria. Usa y ∈ {0, 1}.

Predecir (Logistic Regression)

Devuelve etiquetas binarias (0 o 1) usando el modelo entrenado.

Cost / Gradient (Logistic)

Inspecciona costo y gradiente con un set de pesos arbitrario.

Normalización Z-Score

Normaliza cada columna restando su media y dividiendo por su desviación estándar. Útil antes de entrenar cuando las features tienen escalas muy distintas.

Sigmoid (batch)

Aplica σ(z) = 1 / (1 + e-z) a una lista de valores. Útil para inspeccionar la salida del modelo logístico antes del thresholding.
