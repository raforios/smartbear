# Arte conceptual del portal

SVG dibujados a mano, no generados: pesan ~2 KB cada uno frente a los 7,8 MB de
los PNG anteriores, se ven nítidos en cualquier pantalla y toman el color del
tema con `currentColor`.

Van embebidos en `index.html` para que la página siga siendo un solo archivo.
Si se reemplazan por imágenes generadas, los prompts están en `PROMPTS.md`.
